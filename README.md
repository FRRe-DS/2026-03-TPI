La solución implementa un backend de alta disponibilidad y tolerancia a fallos para la gestión de stock de una cafetería, integrado con un stack completo de observabilidad en tiempo real (métricas, logs estructurados y visualización)

🛠️ **Tecnologías Utilizadas**
**Lenguaje & Framework:** Python 3.10+, FastAPI, Uvicorn
**Base de Datos:** PostgreSQL
**Contenedorización & Orquestación:** Docker, Docker Compose
**Balanceo de Carga:** NGINX
**Observabilidad & Telemetría:** Prometheus, Grafana, Grafana Loki, Promtail
